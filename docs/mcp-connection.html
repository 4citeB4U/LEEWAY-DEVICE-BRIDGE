Private MCP connection

Canonical source in GitHub. Device access is through a separately running, authenticated MCP service using a secure tunnel—not through this static website.

Deployment boundaries

  • GitHub Pages / Vercel: public documentation, device interfaces, deployment descriptors, static assets.
  • Pocket ID: a stateful OIDC identity server that must run on persistent private infrastructure.
  • LeeWay MCP: local canonical Node runtime on the authorized device, with protected read-only discovery tools.
  • ChatGPT: private plugin using the approved secure tunnel and Pocket ID OAuth.

Current verification

Operator connection checks

  1. Confirm the existing Pocket ID deployment is reachable through a stable HTTPS issuer.
  2. Start operator/identity/start-pocket-id-mcp.mjs with the actual resource identifier, owner subject, and the local canonical device configuration.
  3. Confirm http://127.0.0.1:4271/.well-known/oauth-protected-resource/mcp describes the exact registered MCP resource.
  4. Run the approved tunnel-client next to the local MCP server, then complete OAuth authorization in the private ChatGPT plugin.
  5. Verify authenticated bridge_capabilities returns actual live device discovery; discovery is not command authorization.
