The experience for every LeeWay user

One setup. Many devices. Your progress stays yours.

01 / SET UP ONCE

Establish My LeeWay

Authenticate once during account setup, authorize device capabilities and establish independent recovery keys. The configuration belongs to the user's identity, not a permanent single machine.

02 / ADD DEVICES

Bring another device online

Reuse the existing account, create a new unique device identity, approve the hardware and install its compatible signed LeeWay Node. Restore permitted settings without copying private device keys.

03 / RECOVER AND REVIEW

Return after total loss

Use a new machine and an independently accessible recovery method to inspect off-device, encrypted snapshots. Restore the authorized state and resume eligible Agent Lee checkpoints with no unsupported claims of zero data loss.
