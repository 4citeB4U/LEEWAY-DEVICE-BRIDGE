STEP 04

Secondary Workstation Mode

NOT QUALIFIED

Turn this phone into the persistent LeeWay secondary workstation. Android remains the phone runtime; browser/cloud development supplies containerized Linux tooling when desktop-class development is required.

  1. Install/update v0.7.0 from the package above. Do not uninstall an existing app if Android reports a signature conflict.
  2. Open LeeWay Device Bridge and enable LOCAL AGENT SESSION.
  3. Enable ALWAYS-ON REMOTE BRIDGE and keep its foreground notification enabled.
  4. Use SHOW PAIRING TOKEN only when pairing an authorized LeeWay client.
  5. Open the cloud development workspace when container/Linux development is needed.
  6. After pairing, run device.health. The phone is not a verified workstation node until a remote receipt returns without USB.
