### What 24/7 may mean at $0 (honest capability boundary)

1. Public static documentation/Pages can be reachable independently of powered PC, subject to provider uptime.
2. ZITADEL authentication may be available independently of the PC; it does not itself run jobs.
3. Continuity of queued work requires the *existing* Runtime + authoritative durable state to actually survive restarts; no stateful cloud backup is proven here. Free idle-sleep instances can introduce cold starts and loss if storage is ephemeral.
4. Actual Agent Lee loop, GPU inference, voice generation, live camera/Outlook UI require live provisioned compute. No promise of universal always-on work on free hosting.
5. Hosted Veritas needs independently protected signing custody and an independently operated runtime; dual accounts are not a substitute.
